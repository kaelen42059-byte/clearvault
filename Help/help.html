ClearVault Help

ClearVault is a fully accessible, native Windows client for Dropbox, built from scratch for screen reader users. This page is your reference for setup, every feature, and known gotchas.

Getting started: connecting your Dropbox account

ClearVault does not ship with a shared Dropbox connection. Each person who installs it creates their own free Dropbox API app -- this keeps your Dropbox activity private to your own app registration, with no shared limits between users. It takes about two minutes and only needs doing once.

  1. Go to https://www.dropbox.com/developers/apps and sign in with your Dropbox account.
  2. Choose Create app, then Scoped access, then either Full Dropbox or App folder access, give it any name, and create it.
  3. On the app's Settings tab, find Redirect URIs. Type this exact address into the box and press the Add button right next to it -- that saves it immediately, there is no separate Submit button for this field:
    http://127.0.0.1:52874/clearvault/
  4. Also on Settings, find Allow public clients (Implicit Grant & PKCE) and make sure it is switched to Allow.
  5. Go to the Permissions tab and enable: account_info.read, files.metadata.read, files.metadata.write, files.content.read, files.content.write, sharing.read, sharing.write. Press Submit on that tab (Permissions changes do have a Submit button, unlike Settings).
  6. Back on Settings, copy the App key value.
  7. Paste it into ClearVault's first-run setup screen (it appears automatically the first time you run the app).
The App key is a public client identifier, not a secret -- it is fine that ClearVault stores it in plain text. Never paste your App secret or any "generated access token" from that console anywhere; ClearVault never needs them, since it signs in through your real browser instead.

Signing in, switching, and removing accounts

From the main window:

  • Add account... opens your default browser to Dropbox's own sign-in page. Finish signing in there, then return to ClearVault.
  • All signed-in accounts appear in one list. Select one and press Switch to selected to make it active -- no signing out required to change accounts.
  • Remove (sign out) removes an account from ClearVault only. Your files stay safely in Dropbox.
If your browser is already logged into dropbox.com as one account, clicking "Add account" again may skip straight to a consent screen for that same account instead of asking you to log in. To add a genuinely different account, sign into it in a Private/Incognito browser window first, then click "Add account" in ClearVault.

Browsing files

Press Browse files on the main window to open the file browser for the active account. It is a plain list of the current folder's contents (name, type, size, modified date):

  • Enter or Open -- on a folder, goes into it; on a file, downloads a temporary copy and opens it with its normal default app.
  • Backspace or Up one level -- goes to the parent folder.
  • Download... -- saves a permanent copy of the selected file wherever you choose.
  • Refresh -- reloads the current folder.

Creating, renaming, moving, deleting, uploading

  • New folder... -- creates a folder inside the one you're currently browsing.
  • Upload... -- pick one or more local files to upload into the current folder.
  • Rename... or F2 -- rename the selected item.
  • Delete... or Delete -- asks for confirmation first. Dropbox keeps deleted items recoverable for a while, so this is not an instant, unrecoverable loss.
  • Move to... -- asks for a destination folder path (prefilled with your current folder so you can just edit it). There is no visual folder-picker for this yet.

Sharing and copying links

Share / Copy link gets (or reuses, if one already exists) a Dropbox share link for the selected item and copies it straight to your clipboard.

In Preferences, "Direct-download links" controls whether copied links end in dl=1 (downloads the file immediately when opened) instead of Dropbox's default dl=0 (opens a preview page first). On by default.

Search

Search... in the file browser prompts for a search term and opens a results list (name, type, folder, modified date). Press Open or Enter on a file result to open it. Folders in results aren't directly openable from that window -- use the Folder column to know where to browse to.

Background notifications and the tray icon

ClearVault keeps running in the notification area (system tray) after you close the main window -- closing the window just hides it, it does not quit the app. This is what lets background notifications keep working.

  • The tray icon's right-click menu is a plain native Windows menu: Open ClearVault, Check for changes now, and Exit ClearVault.
  • Exit ClearVault from that menu is the only way to fully quit -- closing the window alone does not.
  • About every 90 seconds, ClearVault checks your active account for changes and, if anything changed, shows a short tray notification (for example, "Changed: report.pdf"). This uses Dropbox's ordinary delta API, not instant push, so there can be up to about a minute and a half of delay.

Preferences

Reached via the Preferences... button on the main window. Every setting saves immediately when you change it -- there's no separate Save step.

  • Direct-download links -- see Sharing above.
  • Enable Team integration -- only relevant if your Dropbox account is a member of a Dropbox Business/Team with a team space; does nothing for a personal account. Lets team-space folders show up when browsing.
  • Notify me about Dropbox changes -- turns the tray notifications on or off. Turning it off does not stop ClearVault from running in the tray, only the notifications themselves.

Troubleshooting

"This app has reached its user limit"

A new Dropbox API app starts with a low limit on how many Dropbox accounts it can be linked to while in development status. Go to your app on https://www.dropbox.com/developers/apps and press "Enable additional users" -- this raises the limit to 500 without needing Dropbox's full production review, which is plenty for one person's own app.

"Invalid redirect_uri" when signing in

The redirect URI registered on your Dropbox app doesn't exactly match http://127.0.0.1:52874/clearvault/, including the trailing slash. Double check it under Settings > Redirect URIs, and remember: typing it into the box isn't enough by itself, you also need to press the Add button next to it.

Sign-in seems to silently do nothing, or signs you into the wrong account

See the note under Signing in, switching, and removing accounts above about your browser already being logged into a different Dropbox account.
